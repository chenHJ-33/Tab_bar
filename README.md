# 常驻书签栏新标签页

一个极简的 Chrome 新标签页扩展：**顶部永远有一条书签栏**，访问网站时不显示（Chrome 的原生书签栏保持「仅在新建标签页显示」即可）。

因为 Chrome 不允许扩展控制原生书签栏、也不允许扩展互相往对方的新标签页里注入内容，所以「常驻书签栏」只能由接管新标签页的扩展自己画出来 —— 这就是这个扩展存在的原因。

## 功能

### 书签栏（顶部常驻）

- 读的是你 Chrome 的真实书签栏，**增删改都会实时同步**（新建书签、改名、拖动、导入书签都会自动刷新）
- 文件夹**点击**展开（鼠标只是划过不会自动展开，所以不会出现「点开 A 结果里层的 B 也一起弹开」）；多层嵌套需要**逐层点击**，再点一次收起
- 子文件夹内容多时可以**用鼠标滚轮滚动**查看（菜单最高占屏幕 70%，不会顶出屏幕外）
- 每项显示网站图标（本地生成，不联网）
- 一排放不下时，多出来的自动收进右侧的 **»** 菜单
- 最右侧是 **其他书签**
- 书签栏为空时会显示「点这里添加书签」的入口
- 设置里可切换成**只显示图标**（更紧凑）

### 搜索引擎（搜索框左侧那个胶囊按钮）

- 按钮上会显示**当前引擎的图标**，下拉菜单里每个引擎也带图标
- 图标来自 **Chrome 本地缓存的真实网站 favicon**（`_favicon`，不联网、不上传）；取不到时自动退回内置的彩色徽标，不会出现空白或破图
- 自定义引擎会从你填的模板里自动推出域名取图标（例如填 `https://www.bing.com/search?q=%s` 就用必应的图标）
- 想让某个引擎显示真 logo：用 Chrome 打开一次它的官网（如 `sogou.com`），新标签页里就会变成真图标
- 点搜索框左边的引擎按钮，**随时切换**：跟随浏览器默认 / 百度 / 必应 / 谷歌 / 搜狗 / 360 / DuckDuckGo / 自定义
- 输入框里输入的是网址就直接打开，是关键词就用选中的引擎搜索
- **自定义**：设置里填带 `%s` 的网址模板，例如 `https://www.bing.com/search?q=%s`，保存后即切换过去
- 顺带解决的坑：Chrome 的必应默认引擎会用一个「第三方新标签页」抢走你的新标签页（就是之前那个先闪一下再跳必应的现象）。现在新标签页由本扩展接管，这个机制不会再生效，**搜索引擎可以放心设成必应**

### 搜索联想（搜索框下方的候选）

在搜索框里输入时，下方会弹出候选词，鼠标点或键盘选都行：

- **键盘操作**：`↑` `↓` 上下选择（到底会绕回），`Esc` 关闭候选
- **回车是两步式的**（避免选错词就直接跳走）：
  1. 第一次 `Enter`：把高亮的候选词**填进输入框**，不搜索 —— 你还可以接着改；
  2. 再按一次 `Enter`：**才真正搜索**。
  如果没按 `↑` `↓` 选中任何候选，`Enter` 还是和以前一样直接搜索。
- **鼠标点候选**：明确就要这一条，**填入并直接搜索**（不用按两次）
- **输入 `dee`** → 候选里会有 `deepseek`、`deepseek 官网` 等；候选里**命中你输入的那段字会被高亮**，一眼能看出匹配在哪
- **空输入框聚焦**时，显示**最近 10 条搜索记录**（本地保存），每条右侧有 `✕` 可单独删除
- **在线联想**按当前引擎走各自的官方接口：

  | 引擎 | 联想接口 |
  | --- | --- |
  | 百度 | `www.baidu.com/sugrec` |
  | 必应 | `api.bing.com/osjson.aspx` |
  | 搜狗 | `sor.html5.qq.com/api/getsug`（GBK 编码，已单独处理） |
  | 360 | `sug.so.360.cn/suggest` |
  | 谷歌 | `suggestqueries.google.com` |
  | DuckDuckGo | `duckduckgo.com/ac/` |

  搜狗返回的不是 JSON 而是 `window.sogou.sug([...])` 这种 JS 字面量，代码里按括号配对切出来再解析；解析全部是防御式的，接口改版或返回异常只会得到空候选，不会报错。
- **自动兜底，任何引擎下都有候选**：先问当前引擎自己的接口，**没有接口或连不上就自动换下一家**（百度 → 必应 → 搜狗 → 360 → 谷歌 → DuckDuckGo）。
  - 「跟随浏览器默认」和「自定义」本来就没有联想接口，会自动借用别家；
  - 谷歌 / DuckDuckGo 在国内网络常常连不上，也会自动换到可达的；
  - 借用别家时，下拉表头会标出 **「来自百度」** 这样的来源，不会让你误以为「我选的必应，候选怎么是百度来的」；
  - 当前引擎自己的接口能用时，**永远优先用它**，不会被兜底逻辑抢走。
- **离线 / 超时 / 接口全挂了**：自动退回「本地记录里包含关键词的那几条」，不会弹个空框
- **不打扰输入**：输入的是网址（如 `github.com`）不联想；用输入法打中文时，拼字过程中不会把拼音发出去，等上屏后才联想
- **输入停止约 0.2 秒**才发请求（防抖），同一个词 5 分钟内走本地缓存；连打 `d`→`de`→`dee` 只会发最后一次，旧请求会被中断，不会出现「结果乱序盖住新结果」
- **设置里可以关**（设置 → 搜索联想）：
  - 总开关：不想要候选就整个关掉
  - **联网获取搜索建议**：关掉后只用本地记录，**一个请求都不发**（关键词也就不会交给搜索引擎）
  - 记住最近搜索：控制是否记录、聚焦时是否弹历史；旁边有「清空搜索记录」

> 隐私说明：开启「联网获取搜索建议」时，你**正在输入的关键词**会发给当前选中的搜索引擎（这正是联想词能猜出下文的原因）；当前引擎没有接口或连不上时，还会发给兜底的那一家（表头会标明来源）。其余设置、搜索记录都只存在本机 `chrome.storage.local`，不会上传到任何第三方。介意的话在设置里关掉这一项即可，联想功能会退化成纯本地的「最近搜索」。

### 壁纸

- **上传本地图片**：设置 → 壁纸 → 「上传本地图片…」，**支持多选**，最多 8 张，可反复切换
- **拖拽**：把图片文件直接拖到新标签页任意位置，松手即设为壁纸
- **预设**：4 套内置渐变色
- **图片地址**：粘贴一个 https 图片链接即可
- **遮罩暗度**：滑块调节背景压暗程度，保证白色文字看得清
- 图片会先在本地压缩（最长边 2560px，JPEG），再存进浏览器本地存储，不联网、不上传

### 页面

- 时钟 + 日期
- 常用网站图标网格，可添加 / 悬停删除
- **图标拖动排序**：按住图标拖到别的位置松手即可，左右半区决定插到前面还是后面，会有蓝色指示线；拖到末尾的「+」或图标区空白处则移到最后一格。新顺序自动保存，刷新后保持
- 所有设置都存在本机 `chrome.storage.local`

### 翻译（图标网格下方）

布局与截图一致：上面一行是「源语言 下拉 + 圆形交换按钮 + 目标语言 下拉」，下面是左右两栏「输入文本 / 翻译」。

- **引擎**：百度翻译开放平台「通用文本翻译」，用你申请到的 **AppID（程序 ID）+ 密钥** 调用
- **签名**：`sign = MD5(appid + q + salt + 密钥)`，salt 每次随机，签名在本地算（自带一份 MD5 实现，不联网取脚本）
- **密钥安全**：只写进本机 `chrome.storage.local`，不写进源码、不上传任何第三方；设置里以密码框显示，可点「显示」查看
- **源语言**：默认「自动检测」，另有 28 种语言可选；「自动检测」时点交换按钮会换成「目标语言 → 中文/英语」这种有意义的组合
- **长文本**：按 UTF-8 字节自动切块（单块留有余量，百度单次上限 6000 字节），逐块翻译后拼回，切块不会切断 emoji 等代理对
- **频率限制**：免费版 1 QPS，分块之间自动留间隔；遇到 `54003 / 54005` 会按 0.6s→1.2s→2.4s 退避重试
- **自动翻译**：勾上「自动」后停止输入约 0.7 秒自动翻译；也可以随时点「翻译」或按 `Ctrl + Enter`
- **其它**：右上角显示状态与字数、译文可一键「复制」、输入内容与语言选择都会自动记住
- 报错都会翻译成人话，例如 `54001` → 「签名错误：多半是密钥填错了」、`58000` → 「客户端 IP 非法：去百度翻译控制台把本机 IP 加进白名单」

#### 怎么开通百度翻译

1. 打开 <https://fanyi-api.baidu.com/>，注册并登录
2. 「管理控制台」→「开发者信息」里完成**个人/企业认证**（没认证会报 `52003 / 90107`）
3. 开通「**通用文本翻译**」服务，拿到 **AppID** 和**密钥**
4. 回到新标签页，右下角「设置 → 翻译」，填入 AppID 和密钥，点「保存密钥」
   - 如果你在控制台开了 **IP 白名单**，记得把本机出口 IP 加进去，否则会报 `58000`

> 免费版有字符额度与 1 QPS 限制；额度用尽会返回 `54004`（账户余额不足）。

## 安装

1. 打开 `chrome://extensions`
2. 打开右上角的 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目所在文件夹
4. Chrome 会提示「要更改您的新标签页吗」之类的警告，确认即可（接管新标签页必然的提示）

### 重要：必须禁用其他新标签页扩展（如 iTab）

Chrome 同一时间**只允许一个扩展接管新标签页**。如果 iTab 之类的新标签页扩展也在接管，两者会冲突。

- 在 `chrome://extensions` 里把 **iTab新标签页** 关掉（不用卸载，随时可以再打开）
- 然后新开一个标签页，就能看到顶部的书签栏了

### 改了代码后怎么生效（分阶段发布）

Chrome 的「加载已解压的扩展程序」是**直接以文件夹为扩展本体**的，不是复制一份进去。所以如果直接加载源码目录，每次改动都会立刻被浏览器读到，没法控制「什么时候生效」。

因此本项目采用**源码 / 发布目录分离**：

| 目录 | 用途 |
| --- | --- |
| 项目根目录 | 源码。随便改，浏览器看不到 |
| `dist\` | 发布快照。**Chrome 只加载这个目录** |

**流程：**

1. 在根目录改代码、加功能
2. 功能做完，**双击 `publish.bat`**，源码同步到 `dist\`
3. 打开 `chrome://extensions`，点本扩展卡片上的 **刷新 ↻**
4. 新开一个标签页查看效果

首次使用请把加载目录从项目根目录改成 **`dist`** 子目录（先移除原来那个，再「加载已解压的扩展程序」选 `dist`）。

> `dist\` 已在 `.gitignore` 中，不会提交到仓库。

**为什么需要点刷新 ↻**：`newtab.html`、`css/`、`js/` 的改动其实开新标签页就生效；但 `manifest.json`（权限、版本号）的改动必须点刷新才会被 Chrome 重新解析。养成「同步后点一下刷新」的习惯最省事。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取书签以渲染书签栏（安装时会提示「读取和更改您的书签」） |
| `favicon` | 用 Chrome 本地缓存显示网站图标，不联网、不上传 |
| `storage` | 保存壁纸、搜索引擎、常用网站、搜索记录、翻译密钥等设置 |
| `search` | 「跟随浏览器默认」时用浏览器默认搜索引擎搜索 |
| `host_permissions`（`https://fanyi-api.baidu.com/*`） | 只用于调用百度翻译接口 |
| `host_permissions`（百度 / 必应 / 搜狗 / 360 / 谷歌 / DuckDuckGo 的联想接口域名） | 只用于取搜索建议；在设置里关掉「联网获取搜索建议」后完全不会用到 |
| `chrome_url_overrides.newtab` | 接管新标签页（核心，必需） |

> 扩展页面的 CSP 不允许加载远程脚本，所以联想只能用 `fetch` + `host_permissions`（不能用 JSONP）。上面这些域名就是为此声明的，不涉及任何数据上传。

## 文件结构

```
manifest.json      扩展清单
newtab.html        新标签页结构
css/style.css      样式
js/bar.js          书签栏（读取书签、渲染、文件夹菜单、溢出处理、实时同步）
js/app.js          时钟、搜索引擎、常用网站、壁纸、设置
js/suggest.js      搜索联想（在线联想词、最近搜索、键盘导航、下拉面板）
js/translate.js    翻译面板（百度翻译接口、切块、重试、语言表、界面绑定）
js/md5.js          MD5（算百度翻译的签名，纯本地实现）
publish.bat        发布脚本：同步源码到 dist\
dist/              发布快照，Chrome 实际加载这里（不进版本库）
```

## 已知限制

- **会完全取代 Chrome 的原生新标签页**：没有 Google 搜索框、快捷方式、卡片。这是接管的必然代价。
- 本地壁纸最多 8 张（浏览器本地存储配额约 10 MB，压缩后一般用不到一半）。
- 悬停删除图标后没有撤销，重新加一下即可。
- 没有扩展图标，Chrome 显示默认的拼图图标，不影响功能。
