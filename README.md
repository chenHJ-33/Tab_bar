# 常驻书签栏新标签页

一个极简的 Chrome 新标签页扩展：**顶部永远有一条书签栏**，访问网站时不显示（Chrome 的原生书签栏保持「仅在新建标签页显示」即可）。

因为 Chrome 不允许扩展控制原生书签栏、也不允许扩展互相往对方的新标签页里注入内容，所以「常驻书签栏」只能由接管新标签页的扩展自己画出来 —— 这就是这个扩展存在的原因。

## 功能

### 书签栏（顶部常驻）

- 读的是你 Chrome 的真实书签栏，**增删改都会实时同步**（新建书签、改名、拖动、导入书签都会自动刷新）
- 文件夹**点击**展开（鼠标只是划过不会自动展开，所以不会出现「点开 A 结果里层的 B 也一起弹开」）；多层嵌套需要**逐层点击**，再点一次收起
- 子文件夹内容多时可以**用鼠标滚轮滚动**查看（菜单最高占屏幕 70%，不会顶出屏幕外）
- 每项显示网站图标（本地生成，不联网）
- 一排放不下时，多出来的自动收进右侧的 **»** 菜单
- 最右侧是 **其他书签**
- 书签栏为空时会显示「点这里添加书签」的入口
- 设置里可切换成**只显示图标**（更紧凑）

### 搜索引擎（搜索框左侧那个胶囊按钮）

- 按钮上会显示**当前引擎的图标**，下拉菜单里每个引擎也带图标
- 图标来自 **Chrome 本地缓存的真实网站 favicon**（`_favicon`，不联网、不上传）；取不到时自动退回内置的彩色徽标，不会出现空白或破图
- 自定义引擎会从你填的模板里自动推出域名取图标（例如填 `https://www.bing.com/search?q=%s` 就用必应的图标）
- 想让某个引擎显示真 logo：用 Chrome 打开一次它的官网（如 `sogou.com`），新标签页里就会变成真图标
- 点搜索框左边的引擎按钮，**随时切换**：跟随浏览器默认 / 百度 / 必应 / 谷歌 / 搜狗 / 360 / DuckDuckGo / 自定义
- 输入框里输入的是网址就直接打开，是关键词就用选中的引擎搜索
- **自定义**：设置里填带 `%s` 的网址模板，例如 `https://www.bing.com/search?q=%s`，保存后即切换过去
- 顺带解决的坑：Chrome 的必应默认引擎会用一个「第三方新标签页」抢走你的新标签页（就是之前那个先闪一下再跳必应的现象）。现在新标签页由本扩展接管，这个机制不会再生效，**搜索引擎可以放心设成必应**

### 壁纸

- **上传本地图片**：设置 → 壁纸 → 「上传本地图片…」，**支持多选**，最多 8 张，可反复切换
- **拖拽**：把图片文件直接拖到新标签页任意位置，松手即设为壁纸
- **预设**：4 套内置渐变色
- **图片地址**：粘贴一个 https 图片链接即可
- **遮罩暗度**：滑块调节背景压暗程度，保证白色文字看得清
- 图片会先在本地压缩（最长边 2560px，JPEG），再存进浏览器本地存储，不联网、不上传

### 页面

- 时钟 + 日期
- 常用网站图标网格，可添加 / 悬停删除
- **图标拖动排序**：按住图标拖到别的位置松手即可，左右半区决定插到前面还是后面，会有蓝色指示线；拖到末尾的「+」或图标区空白处则移到最后一格。新顺序自动保存，刷新后保持
- 所有设置都存在本机 `chrome.storage.local`

## 安装

1. 打开 `chrome://extensions`
2. 打开右上角的 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目所在文件夹
4. Chrome 会提示「要更改您的新标签页吗」之类的警告，确认即可（接管新标签页必然的提示）

### 重要：必须禁用其他新标签页扩展（如 iTab）

Chrome 同一时间**只允许一个扩展接管新标签页**。如果 iTab 之类的新标签页扩展也在接管，两者会冲突。

- 在 `chrome://extensions` 里把 **iTab新标签页** 关掉（不用卸载，随时可以再打开）
- 然后新开一个标签页，就能看到顶部的书签栏了

### 改了代码后怎么生效（分阶段发布）

Chrome 的「加载已解压的扩展程序」是**直接以文件夹为扩展本体**的，不是复制一份进去。所以如果直接加载源码目录，每次改动都会立刻被浏览器读到，没法控制「什么时候生效」。

因此本项目采用**源码 / 发布目录分离**：

| 目录 | 用途 |
| --- | --- |
| 项目根目录 | 源码。随便改，浏览器看不到 |
| `dist\` | 发布快照。**Chrome 只加载这个目录** |

**流程：**

1. 在根目录改代码、加功能
2. 功能做完，**双击 `publish.bat`**，源码同步到 `dist\`
3. 打开 `chrome://extensions`，点本扩展卡片上的 **刷新 ↻**
4. 新开一个标签页查看效果

首次使用请把加载目录从项目根目录改成 **`dist`** 子目录（先移除原来那个，再「加载已解压的扩展程序」选 `dist`）。

> `dist\` 已在 `.gitignore` 中，不会提交到仓库。

**为什么需要点刷新 ↻**：`newtab.html`、`css/`、`js/` 的改动其实开新标签页就生效；但 `manifest.json`（权限、版本号）的改动必须点刷新才会被 Chrome 重新解析。养成「同步后点一下刷新」的习惯最省事。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取书签以渲染书签栏（安装时会提示「读取和更改您的书签」） |
| `favicon` | 用 Chrome 本地缓存显示网站图标，不联网、不上传 |
| `storage` | 保存壁纸、搜索引擎、常用网站等设置 |
| `search` | 「跟随浏览器默认」时用浏览器默认搜索引擎搜索 |
| `chrome_url_overrides.newtab` | 接管新标签页（核心，必需） |

## 文件结构

```
manifest.json      扩展清单
newtab.html        新标签页结构
css/style.css      样式
js/bar.js          书签栏（读取书签、渲染、文件夹菜单、溢出处理、实时同步）
js/app.js          时钟、搜索引擎、常用网站、壁纸、设置
publish.bat        发布脚本：同步源码到 dist\
dist/              发布快照，Chrome 实际加载这里（不进版本库）
```

## 已知限制

- **会完全取代 Chrome 的原生新标签页**：没有 Google 搜索框、快捷方式、卡片。这是接管的必然代价。
- 本地壁纸最多 8 张（浏览器本地存储配额约 10 MB，压缩后一般用不到一半）。
- 悬停删除图标后没有撤销，重新加一下即可。
- 没有扩展图标，Chrome 显示默认的拼图图标，不影响功能。
